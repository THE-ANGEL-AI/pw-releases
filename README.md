# Помощник Perfect World — релиз

Здесь лежат **только готовые сборки** приложения и файлы автообновления.

**Исходного кода в этом репозитории нет и не будет.** Он хранится отдельно и в публичный доступ не выкладывается.

## Что здесь

| Файл | Зачем |
|---|---|
| `PerfectWorld-<версия>-Setup.exe` | Установщик для Windows |
| `latest.yml` | Метаданные автообновления (версия, размер, `sha512`) |
| `*.blockmap` | Данные для дельты — быстрое обновление |

## Скачать

Актуальная версия всегда доступна по постоянной ссылке:

```
https://github.com/THE-ANGEL-AI/pw-releases/releases/latest
```

Приложение само проверяет обновления: тихо при запуске (не чаще раза в сутки) и по кнопке «Проверить обновление» в диалоге «О программе».

## О проекте

**Помощник Perfect World** — неофициальный локальный помощник игроков: считает прогноз фарма по ресурсам, ведёт склад, персонажей и ежедневное расписание.

- Издатель: The Angel Studio
- Официальная группа: https://vk.ru/gi_the_angel
- Требования: Windows 10/11 (x64)

Проект **не связан с правообладателем игры**. Товарные знаки и фирменный стиль не используются, логотипы не применяются.

## Данные и приватность

Приложение работает полностью локально: расчёты и данные хранятся только на компьютере пользователя, в `%APPDATA%\TheAngelLab`. Сеть используется исключительно для проверки обновлений. Профиль не отправляется никуда.

## Предупреждение Windows

Сборки не подписаны сертификатом издателя, поэтому SmartScreen может показать предупреждение «Windows защитила ваш компьютер». Выберите **«Подробнее» → «Выполнить в любом случае»**.

Контрольная целостность файла проверяется приложением по `sha512` из `latest.yml` — подменённый файл будет отклонён.
